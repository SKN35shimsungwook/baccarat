# 바카라 테이블 (Streamlit)

8덱 슈로 진행하는 1인용 바카라 게임입니다. 라이브 카지노 테이블처럼 칩 베팅, 카드 스퀴즈, 출목표 5종을 제공합니다.
**칩은 가상 칩**이며 시작 금액은 사이드바에서 직접 정합니다.

## 실행

```bash
pip install -r requirements.txt
streamlit run main.py
```

테스트:

```bash
python -m pytest -q
```

### 디자인

- 카드: 동양화풍 카드팩 시트에서 52장과 뒷면을 잘라낸 이미지(220×340)를 사용합니다.
- 테이블: 딜러 무대 → 붉은 펠트(금박 세이가이하 물결무늬, 검은 가죽 테두리) → 옻칠 컨트롤 바 → 한지 톤 출목표판.
- 글꼴: Cinzel(영문), Noto Serif KR(한글). Google Fonts에서 불러옵니다.
- 사이드바에서 딜러(남성/여성)와 카드 공개 방식을 고릅니다.
  - **딜러가 공개**: 카드가 딜러 쪽에서 날아와 놓이고, 각 손의 첫 장은 바로 뒤집고 둘째 장·3번째 카드는 딜러가 천천히 젖힙니다.
  - **직접 스퀴즈**: 카드를 드래그해서 직접 젖힙니다.
  - 딜러 영상은 동작별 구간으로 나뉘어 있고, 카드 공개와 맞춰 재생됩니다.

    | 구간 | 딜러 동작 | 그동안 테이블에서 |
    |---|---|---|
    | deal | 슈에서 카드를 꺼낸다 | 카드 4장 분배 |
    | player | 왼쪽(플레이어 쪽)으로 손을 뻗는다 | 플레이어 카드 공개 |
    | banker | 오른쪽(뱅커 쪽)으로 손을 뻗는다 | 뱅커 카드 공개 |
    | show | 카드를 들어 보인다 | 3번째 카드 |

  - 남성 딜러의 show 구간은 딜러가 든 카드 위치를 프레임마다 추적해 두어서, 그 자리에 **실제 3번째 카드 이미지**를 덮어씌웁니다.
    여성 딜러 영상에는 카드를 들어 보이는 장면이 없어서, 가운데에서 카드를 다루는 동작을 쓰고 카드는 덮어씌우지 않습니다.
  - 영상은 원본(1366×768)의 위쪽 456픽셀만 씁니다. 원본 아래쪽 테이블의 블랙잭 문구가 보이지 않게 하기 위해서입니다.
  - 원본 영상을 바꾸면 `python tools/build_dealer_clips.py <원본 폴더>`로 다시 만듭니다. 이 스크립트에는 `pip install opencv-python imageio-ffmpeg`가 필요합니다(게임 실행에는 필요 없음). 구간(프레임 번호)은 스크립트 위쪽 `SEGMENTS`에서 고칩니다.
- 반응형 기준은 창 너비가 아니라 테이블 너비(container query)라서 사이드바를 열어도 레이아웃이 유지됩니다.

### 화면과 파이썬이 주고받는 방식

```
[테이블 화면 JS]                               [파이썬]
 칩 놓기 / 되돌리기 / 2배 / 재베팅 (화면 안에서만)
 딜 ── setTriggerValue("deal", {bets}) ──▶  on_deal(): 검증 → 칩 차감 → 분배 → 정산 → 출목표
 카드 분배·스퀴즈·정산 연출 ◀── data={outcome, roads, ...} ──┘
```

승패는 항상 파이썬이 정하고 화면은 결과를 연출만 합니다. 브라우저를 조작해도 결과는 바뀌지 않습니다.

## 베팅 기록

위쪽 메뉴의 **베팅 기록** 페이지에서 볼 수 있습니다.

- 요약: 총 판수, 총 베팅액, 순손익(베팅액 대비 %), 이긴 판 수, 최대 수익·손실
- 칩 잔액 추이 그래프 (점선은 시작 칩)
- 베팅 종류별 손익 그래프와 표 (건수, 적중률, 베팅액, 돌려받은 금액, 손익)
- 판별 기록 표 (시각, 슈 번호, 베팅 내역, 결과, 양쪽 카드, 손익, 잔액). 전체 / 이긴 판 / 진 판으로 거를 수 있습니다.
- CSV 내려받기 (엑셀에서 한글이 깨지지 않게 UTF-8 BOM으로 저장)

기록은 칩과 마찬가지로 이번 세션에만 저장되어, 페이지를 새로 고침하면 초기화됩니다.

## 규칙

| 베팅 | 배당 | 하우스 에지 (8덱) |
|---|---|---|
| 뱅커 | 0.95:1 (노 커미션 모드: 1:1, 6점 승은 0.5:1) | 1.06% (노 커미션 1.46%) |
| 플레이어 | 1:1 | 1.24% |
| 타이 | 8:1 또는 9:1 | 14.36% / 4.84% |
| P 페어 / B 페어 | 11:1 | 10.36% |
| 타이거 (뱅커 6점 승) | 2장 12:1 / 3장 20:1 | 16.68% |

- 타이가 나오면 플레이어/뱅커 베팅은 환불됩니다.
- 플레이어와 뱅커에 동시에 걸 수 없습니다.
- 소수점 이하 당첨금은 버립니다 (예: 뱅커 1,010 적중 → 959 지급).
- 컷 카드는 슈 끝에서 16번째 위치입니다. 컷 카드가 나온 판까지 진행하고 슈를 마감합니다.
- 하우스 에지는 `engine/odds.py`가 슈 전체 조합을 계산한 값이고, `tests/test_odds.py`가 알려진 수치와 일치하는지 확인합니다.

## 출목표

- **주구로**: 결과를 순서대로 위→아래로 기록합니다.
- **원매**: 같은 쪽 연승을 한 열로 묶습니다. 6칸을 넘으면 오른쪽으로 꺾입니다(드래곤테일). 타이는 직전 칸에 초록 사선으로 표시합니다.
- **대안길 / 소안길 / 갑을길**: 원매의 1/2/3열 전과 비교해서 규칙적이면 빨강, 불규칙하면 파랑으로 표시합니다.
- **예측(뱅/플)**: 다음 판이 뱅커 또는 플레이어라면 세 파생 도로에 어떤 색이 찍힐지 보여줍니다.

## 칩 시스템 교체

게임 엔진은 `wallet.Wallet` 인터페이스만 사용합니다. 계정별 저장이나 출석 보너스 같은 가상 포인트 방식으로 바꿀 때는
`Wallet`을 상속한 구현체를 새로 만들고 `main.py`에서 `SessionWallet` 대신 넣으면 됩니다.
실제 돈으로 충전하거나 칩을 현금·상품권으로 바꾸는 기능은 넣지 않습니다.
